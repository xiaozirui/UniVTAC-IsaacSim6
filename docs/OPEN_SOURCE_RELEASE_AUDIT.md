The root Apache License 2.0 text and upstream attribution are retained. Genuinely modified comment-safe source files carry derivative modification notices. The upstream README/root-LICENSE mismatch is recorded without reinterpretation.

## Remaining uncertainties within published files

None identified by the repository scan. Third-party and asset uncertainties remain outside the published scope and must not be reintroduced without a new audit.
